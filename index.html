SKYFALL ROYALE

Eigenständiger 3D-Battle-Royale-Prototyp mit 24 Bots + bis zu 2 menschlichen Spielern.

Der Raumcode wird nach dem Beitritt angezeigt. Im LAN öffnet dein Freund dieselbe Server-Adresse mit dem gleichen Raumcode. Für Internet-Multiplayer muss der Server öffentlich erreichbar sein (z.B. VPS oder Portweiterleitung).

WASD = bewegen · Maus = schauen
Linksklick = schießen · R = nachladen
SPACE = aus Flugzeug springen
E = Loot aufnehmen · B = Wand · N = Treppe
ESC = Maus freigeben
Baumodus: B Wand / N Treppe
